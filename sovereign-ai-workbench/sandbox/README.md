# Sandbox Module

## Purpose
Provides secure, isolated micro-containers and jails to execute untrusted code generated by autonomous agents and LLMs safely without exposing host infrastructure.

## Phase Milestone
Targeted for **Phase 6: Isolated Code Sandbox**.

## Subcomponents to be implemented:
- `docker_runner.py`: Ephemeral Docker container manager.
- `limits.py`: Resource quotas (CPU, memory, execution timeouts).
- `security_filters.py`: System call interception and blocked command heuristics.
